# GitHub Portfolio Roadmap

## Purpose

Build a coherent portfolio demonstrating the ability to connect technology, project execution, business context, and human-capital considerations.

## Portfolio sequence

1. AI & Quantum Human Capital
2. AI & LLM Applications
3. Cloud Technology Lab
4. Embedded Systems Lab
5. VLSI & Semiconductor Technology
6. Technology Project Management Toolkit
7. Technical Foundations

## Principles

- Prefer meaningful projects over tutorial collections.
- Document the problem, requirements, approach, decisions, results, and lessons learned.
- Show technical progression without overstating current capability.
- Use code where it adds value, not merely to make a repository look technical.
- Connect technical work to project, product, organizational, or business outcomes.
